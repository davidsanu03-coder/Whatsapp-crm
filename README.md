# Royexa CRM

An omnichannel CRM foundation focused on leads, conversations, follow-ups and sales pipelines.

## What it demonstrates

- Lead management and CRM workflows
- WhatsApp-first conversation management
- Follow-up and pipeline tracking
- AI assistant integration
- Authentication and protected application flows
- Supabase-backed data and realtime capabilities
- API integration and frontend state management

## Technology

- React
- JavaScript
- Vite
- Supabase PostgreSQL
- Supabase Auth
- Supabase Realtime
- AI / LLM integration
- API integration

## Local development

```bash
npm install
npm run dev
```

Configure the required Supabase environment variables before running the application.

## Product direction

Royexa CRM is being developed toward a broader omnichannel platform covering conversations, lead management, follow-ups, analytics, AI assistance and business workflows.
